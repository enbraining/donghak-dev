# KT Cloud Zone

KT Cloud는 4개의 데이터센터와 12개의 서비스 존으로 구성됩니다.

## Public Service

- Central A/B Zone: 기본 서비스 Zone이다.
- Seoul M/M2 Zone: 서울에 있는 독립된 Zone, M2 Zone은 기업 특화된 고성능 Zone
- Cloud-HA Zone: 남부에 위치한 DR 대비 구성 Zone이다.

## Enterprise Service

- Enterprise Zone: 천안에 위치한 보안에 특화된 기업용 Zone
- G-Cloud Zone: 천안에 위치한 보안에 특화된 공공기관 전용 Zone
- Enterprise Security Zone: 목동에 위치한 보안 특화 Zone

# VR(Virtual Router)

KT Cloud 내부에 있는 VM과 외부와의 통신을 중개합니다.

- NAT: 사설망과 공인망을 중개
- 방화벽: Inbound 트래픽에 대한 Source IP/Port를 허용
- DHCP: KT Cloud 내부에 VM 생성 시 사설 IP 주소 부여
