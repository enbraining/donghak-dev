# NCP Nuke

[NCP Nuke](https://github.com/enbraining/ncp-nuke)는 네이버 클라우드 플랫폼(Naver Cloud Platform, NCP)의 서브 계정(Sub Account)을 효율적으로 관리하고, 필요 시 리소스를 일괄 삭제(Nuke)할 수 있도록 돕는 CLI 도구입니다.

주로 교육 환경이나 다수의 계정을 동시에 초기화해야 하는 상황에서 유용하게 사용할 수 있습니다.

## 주요 기능

### 1. 일괄 조회 (List)
등록된 모든 루트 계정 하위의 서브 계정 정보를 테이블 형태로 조회할 수 있습니다.

### 2. 일괄 활성화 (Activate)
모든 서브 계정을 활성화 상태로 변경하고, 비밀번호를 지정된 값으로 일괄 초기화합니다.

### 3. 일괄 비활성화 및 정리 (Deactivate & Nuke)
서브 계정을 비활성화하여 로그인을 차단할 수 있습니다.
특히 `--cleanup` 옵션을 사용하면 해당 서브 계정에 연결된 **모든 리소스(서버, 스토리지, 공인 IP, NAS, 로드밸런서 등)를 영구적으로 삭제**한 후 계정을 비활성화합니다.

> **주의:** `--cleanup` 옵션은 삭제된 리소스를 복구할 수 없으므로 프로덕션 환경에서는 각별한 주의가 필요합니다.

## 사용 방법

이 도구는 엑셀 파일(`.xlsx`)을 통해 루트 계정의 인증 정보(Access Key, Secret Key)와 관리할 서브 계정 정보를 정의하여 작동합니다. 우선 템플릿 파일을 생성한 뒤 정보를 입력해야 합니다.

Go 언어로 작성되었으며, [GitHub 저장소](https://github.com/enbraining/ncp-nuke)에서 릴리스된 바이너리를 다운로드하거나 소스를 직접 빌드하여 사용할 수 있습니다.

```bash
# 템플릿 엑셀 파일 생성
ncp-nuke template

# 서브 계정 목록 조회
ncp-nuke list --file accounts.xlsx

# 서브 계정 활성화 및 비밀번호 초기화
ncp-nuke activate --file accounts.xlsx --password "NewPassword123!"

# 리소스 정리 후 서브 계정 비활성화
ncp-nuke deactivate --file accounts.xlsx --cleanup
```
